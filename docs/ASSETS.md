## 2. Arte y Renders de Persona 3 Reload
- **Archivos locales**:
  - `src/assets/p3r/char1.png`: Cut-in de combate de Makoto Yuki (resolución original, sombreado angular azul).
  - `src/assets/p3r/char2.png`: Cut-in de Junpei Iori (variante para selección o análisis ofensivo).
  - `src/assets/p3r/char3.png`: Cut-in de Yukari Takeba (variante para análisis de soporte o tirador).
  - `src/assets/p3r/makoto_p3hero.png`: Silueta y render frontal de Makoto Yuki para cabeceras y dashboard.
  - `src/assets/p3r/makoto_ui_texture.png`: Textura de trama y motivo visual Dark Hour.
